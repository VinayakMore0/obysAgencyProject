# 🚀 Obys Agency Project

## Overview
This project is a clone of the award-winning Obys Agency website, showcasing advanced web development techniques with a focus on creating immersive user experiences. The implementation demonstrates proficiency in modern front-end development practices and animation technologies.

## 📋 Key Features
- **Immersive Animations**: Fluid transitions and engaging visual effects that enhance user experience
- **Responsive Design**: Fully adaptive layout for seamless viewing across all device types
- **Modern Tech Stack**: Implementation using cutting-edge web development technologies
- **Performance Optimized**: Fast loading times with efficient resource management

## 🛠️ Technologies Used
- **HTML5** - Semantic markup structure
- **CSS3** - Advanced styling with modern CSS features
- **JavaScript** - Interactive elements and dynamic content
- **GSAP (GreenSock Animation Platform)** - Professional-grade animations
- **Locomotive Scroll** - Smooth scrolling experience
- **ThreeJS** - 3D graphics and effects

## 🔍 Project Structure
The repository is organized with a clean architecture:
- `assets/` - Contains images, icons, and other static resources
- `scripts/` - JavaScript files for various functionalities
- `styles/` - CSS styling organized by components
- `index.html` - Main entry point of the application

## ⚙️ Implementation Details
This project faithfully recreates the unique aesthetic and functional features of the original Obys Agency website, with particular attention to:

1. **Loading Animation**: Custom-designed entry sequence that sets the tone for the user experience
2. **Navigation System**: Intuitive and visually consistent menu interactions
3. **Scroll Behaviors**: Custom scroll events that trigger animations and content transitions
4. **Visual Effects**: Particle systems, hover effects, and micro-interactions throughout the interface
